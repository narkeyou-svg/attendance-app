# タイムレコーダー・出退勤管理システム (勤怠管理)

従業員20名規模向けのワンタップ出退勤・誤打刻修正・残業時間集計＆Excel出力システムです。
Webブラウザ上で動作し、オフィスの共有PCやiPadなどの共有端末でも快適にご利用いただけます。

---

## 🌟 主な機能

1. **お年寄りも迷わないシンプル打刻**
   - 画面上はお名前と出勤状況（出勤中・未出勤・退勤済）だけのすっきりした表示。
   - お名前をタップすると特大の【出勤】【退勤】ボタンが表示され、確認ステップで押し間違いを防止。
2. **誤打刻の修正・取り消し機能**
   - 直前打刻のワンクリック取り消し（Undo）機能。
   - タイムカード画面からいつでも時刻修正・手動追記・修正理由の記録が可能。
3. **給与計算・締め処理サポート**
   - 締め前エラーチェック（退勤押し忘れ等の自動検出）。
   - 普通残業（1.25倍手当）、深夜労働（0.25倍手当）、総支給額の自動算出。
   - 従来の「紙のタイムカード様式」A4用紙印刷・PDF保存。
4. **エクセル出力 (Excel .xlsx / CSV)**
   - 給与計算用集計表、全社員一括台帳、給与ソフト用CSV（弥生・freee・MF等）。

## ❓ データベース（DB）は必要？ブラウザを閉じたら消える？

### Q1. ブラウザを閉じたらデータは消えてしまう？
**A. 通常の「閉じる」操作やPCの再起動では【消えません】。**
本システムはブラウザの「LocalStorage（ローカル保管領域）」にデータを書き込んでいます。
これは一時的なメモリではなく、お使いのパソコンのSSD・ハードディスクに保存されるため、ブラウザを閉じても、パソコンの電源を切っても、次回開いたときにデータがそのまま残ります。

> **※データが消える例外（注意点）**:
> 1. ブラウザの「閲覧履歴・Cookie・キャッシュの削除」を手動で行った場合
> 2. 「シークレットモード（プライベートウィンドウ）」で開いている場合

### Q2. データベース（DB）は本当に必要ないの？
**A. 「どう運用するか」によって変わります。**

- **オフィスの1台のPCやiPadを受付に置き、みんながそこに来て打刻する場合（タイムカード置場と同じ運用）**:
  - 👉 **データベース（DB）は不要です！** その端末のブラウザ内にデータが蓄積され続けるため、無料・追加設定なしでそのまま運用できます。
- **複数端末でデータを共有したい場合（例: 社員のスマホからも打刻したい、自宅のPCから集計を見たい）**:
  - 👉 **クラウド上のデータベース（Firebaseなど）が必要になります。** LocalStorageはその端末の中にしか保存されないため、別のスマホやPCからは見ることができないためです。

## 🌐 Render 等のインターネット上に無料で公開（デプロイ）する手順

無料のホスティングサービス **Render (render.com)** を使えば、5分ほどでインターネット上に公開できます。

### 手順：
1. **GitHubにコードをアップロード**:
   - GitHubで新しいリポジトリを作成し、解凍したプロジェクトのファイル一式をプッシュ（アップロード）します。
2. **Render にログイン**:
   - [Render (https://render.com/)](https://render.com/) で無料アカウントを作成し、ログインします。
3. **新規サイトを作成**:
   - 画面右上の **「New +」** → **「Static Site」** を選択します。
   - 連携した GitHub リポジトリを選択します。
4. **設定を入力**:
   - **Name**: お好きな名前（例: `my-attendance-app`）
   - **Build Command**: `npm run build`
   - **Publish Directory**: `dist`
5. **「Create Static Site」をクリック**:
   - 自動でビルドが始まり、1〜2分で `https://xxxx.onrender.com` という公開URLが発行されます！
   - このURLをオフィスのPCやiPadのブラウザでブックマークすれば、どこからでもアクセスできるようになります。

## 💻 自分のPC（ローカル環境）で動かす手順

### 準備（初回のみ）
1. [Node.js 公式サイト](https://nodejs.org/) より LTS版（推奨版）をダウンロードしてインストールしてください。

### 起動方法
1. このフォルダをPCのお好きな場所（デスクトップなど）に配置します。
2. **Windowsの場合**: フォルダ内の `start.bat` をダブルクリックするだけで自動起動します。
3. **Macの場合**: フォルダ内でターミナルを開き、以下を実行します：
   ```bash
   npm install   # 初回のみ（必要な部品のインストール）
   npm run dev   # 起動
   ```
4. ブラウザで **http://localhost:3000** を開くと起動します。
